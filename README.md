# Investment Research Copilot

AI-assisted investment research application.

The goal of this project is to help users research public company
information such as financial results and disclosure documents.

## Goals

- Extract financial metrics
- Calculate financial changes using deterministic code
- Search disclosure documents with RAG
- Generate grounded answers with sources
- Evaluate retrieval and answer quality
- Provide an iOS / SwiftUI interface

## Non-goals

This project does not:

- execute trades
- predict stock prices with certainty
- provide investment recommendations

The application is intended for research and learning purposes.
